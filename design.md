# Journel X - Mobile App Design

## Overview
Journel X is an offline journaling app that mimics the experience of writing in an old, worn book. The app provides a warm, nostalgic aesthetic with handwriting-style text input and multiple chapters for organizing thoughts.

## Screen List

1. **Home Screen (Book View)** - Main writing interface displaying the current chapter as an open book
2. **Chapter List Screen** - Browse and manage all chapters
3. **Chapter Detail Screen** - View and edit a specific chapter's content
4. **Settings Screen** - Pen color selection and app settings
5. **Credits Screen** - Developer information and social links

## Primary Content and Functionality

### Home Screen (Book View)
- Display the current chapter as an open book with aged, yellowed pages
- Text input area styled as handwriting
- Pen color indicator (black or blue)
- Quick access to chapter list
- Save indicator

### Chapter List Screen
- List of all chapters with creation date
- Create new chapter button
- Delete chapter option
- Navigate to chapter detail

### Chapter Detail Screen
- Full chapter content display
- Edit mode for adding/modifying text
- Handwriting-style font rendering
- Pen color selection (black/blue)
- Auto-save functionality

### Settings Screen
- Pen color toggle (Black / Blue)
- App information

### Credits Screen
- Developer name: "Developed by IPlaysDev"
- Clickable links:
  - GitHub: https://github.com/IPlaysDev
  - YouTube: https://www.youtube.com/@IPlaysDev
  - Instagram: https://www.instagram.com/iplaysdev

## Key User Flows

1. **Writing a New Entry**
   - User opens app → Home screen displays current chapter
   - User taps text area → Keyboard appears
   - User types → Text appears in handwriting style
   - User selects pen color (black/blue) → Text color changes
   - Content auto-saves to local storage

2. **Creating a New Chapter**
   - User taps "New Chapter" button → Chapter creation dialog
   - User enters chapter name → Chapter added to list
   - User navigates to new chapter → Empty book page appears
   - User begins writing

3. **Accessing Credits**
   - User navigates to Credits screen
   - User taps social media links → Opens in browser

## Color Choices

- **Page Background**: #F5E6D3 (Old yellowed paper)
- **Text Color (Black Pen)**: #1A1A1A (Deep black)
- **Text Color (Blue Pen)**: #2E5090 (Classic blue ink)
- **Book Binding**: #8B7355 (Brown leather)
- **Accent Color**: #D4A574 (Gold/tan for highlights)
- **Border/Shadow**: #A89968 (Aged paper shadow)

## Typography

- **Handwriting Font**: "Caveat" or similar handwriting-style font for text input
- **UI Text**: Clean sans-serif (system font) for navigation and controls
- **Font Size**: Large enough for comfortable reading on mobile (16-18px for body text)

## Visual Style

- Aged, worn book aesthetic with subtle texture
- Soft shadows and rounded corners for comfort
- Warm color palette (yellows, browns, tans)
- Minimal UI chrome to focus on the writing experience
- Subtle animations for page transitions
